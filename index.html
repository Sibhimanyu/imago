Imago in 30 seconds

        
A PokeAPI response becomes a profile, a forecast gets watched, and the model sends a plan instead of HTML. It has sound.

      

      
      
Amigo, the mascot, is buried under 15,411 lines of JSON. A GET URL is pasted into Imago, the response is read as a shape, and pages appear for a Pokémon, a forecast and exchange rates. A watched value changes and is marked. It ends on the Imago logo and imago.onslate.in.

    


    

      

        
Reads the shape

        
Values become types, types become a fingerprint. Two responses with the same structure share one design.

        
a3f9c1e0{ "temperature": "number" }

      

      

        
Remembers it

        
A shape it has seen before costs no model call. Refresh an endpoint for an hour and pay for one design.

Watches it change

        
Auto-refresh every 10, 30 or 60 seconds. The values that moved are marked, not buried.

What else it does

      

        
Takes a curl command

        
Paste what "Copy as cURL" gives you. The URL goes in the bar and the headers go in Inspect. -u becomes Basic auth.

      

      

        
Follows links

        
A URL in the response opens as the next page. Back walks the trail you took, one page at a time.

      

      

        
Lets you edit the page

        
Rename a field, move it to the headline or hide it. The edit applies to every endpoint that returns the same shape.

      

      

        
Shares what you see

        
A link opens the same page for someone else, even without a key. It never carries your headers, keys or the response.

      

      

        
Tells you when you are away

        
A watched page that changes puts a count in the tab title, and sends a notification if you allowed one.

      

      

        
Works with no key

        
The basic layout is built from the response alone: units rejoined, time series charted, bookkeeping folded into Details.

      

    


    

      
How it works

      
    
        
  1. Fetch
    Your browser calls the endpoint. There is no Imago server in between.
    2. 
        
  2. Fingerprint
    Values are replaced by their types and the result is hashed.
    3. 
        
  3. Plan, once
    A new shape asks the model for a small JSON plan: which fields matter and how to show each. You press the button first.
    4. 
        
  4. Render
    Imago's own components draw the plan. The model never returns HTML, and every value is written as text.
    5. 
      

      
Limits. GET only. The API has to allow web pages (CORS); when one does not, Imago says so instead of failing quietly. Keys stay in this browser, and request headers are gone when the tab closes.

    


    
    

      
Free, and why

      

        
Free forever

        
Bring your own free Gemini or Groq key, or use none: the basic layout needs no key. Imago has no server, so there is nothing to charge for. Your key stays in your browser and goes only to the provider you chose.

        
MIT licensedNo account
