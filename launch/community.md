# Community: a place to talk

<https://github.com/Sibhimanyu/imago/discussions>

GitHub Discussions, one tab from the code, because that's where an
open-source project's users look. It opened with threads that are useful
before anyone replies, so the first visitor finds something there.

| Thread | Section | Why it's there |
|---|---|---|
| [Welcome: what Discussions is for](https://github.com/Sibhimanyu/imago/discussions/13) | Announcements | What goes where: Q&A, Show and tell, Ideas; bugs to Issues with a Share link |
| [APIs that work with Imago](https://github.com/Sibhimanyu/imago/discussions/14) | General | A list of public, keyless, CORS-friendly APIs with Open in Imago links. People add to it, so it grows without me |
| [Why does an API say it does not allow browser apps?](https://github.com/Sibhimanyu/imago/discussions/15) | Q&A | The error most people hit first (CORS), with the answer marked |
| [Share a page Imago drew](https://github.com/Sibhimanyu/imago/discussions/16) | Show and tell | Pages people made, with Share links |
| [What should Imago draw better?](https://github.com/Sibhimanyu/imago/discussions/17) | Ideas | Suggestions, and the honest limit: GET only, public endpoints |
| One thread per gallery API ([PokeAPI](https://github.com/Sibhimanyu/imago/discussions/18), [Open-Meteo](https://github.com/Sibhimanyu/imago/discussions/19), [Open Library](https://github.com/Sibhimanyu/imago/discussions/20), [Frankfurter](https://github.com/Sibhimanyu/imago/discussions/21), [Wikipedia](https://github.com/Sibhimanyu/imago/discussions/22), [ISS](https://github.com/Sibhimanyu/imago/discussions/23)) | General | Linked from each gallery page as "Discuss this API", so the conversation starts where visitors land |

The new-issue page links here for questions and ideas.
