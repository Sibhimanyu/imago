The mark — “Emergence”

Three loose rows resolve into one solid form. Read left to right it is the product: raw data becomes a rendered interface. The rows grow toward the block so the eye travels in the direction of the transformation. An imago is the final, fully-formed stage after metamorphosis — the mark is that arrival, not the process.

Clear space — keep one block-width (the tall form) clear on every side. Minimum size 16px; below that use the app icon, never the bare mark. The mark is single-colour and never gradient, outlined, rotated, or stretched.

Colour — every value means something

Paper #f6f5f1The page. Warm grey, never white — this is a reading surface for dense JSON.
Ink #1b1b19Text, the mark, primary actions. Near-black, never #000.
Amber #f5ce47Something changed. The only decorative-looking colour, and it is never decorative.
Green #4fa96aLive, generated, succeeded. Auto-refresh pulse.
Red #d9534fFailed. Errors and destructive actions only.
Blue #4f86c6Links and numeric tokens in code.
Line #e7e5dfBorders and rules. Structure comes from lines, not shadows.
Muted #8a8981Labels and secondary text.

Stat bars are the one exception — they run a six-step spectrum (red → amber → green) so ranked values can be compared at a glance. Outside charts, never introduce a colour without a meaning.

Inter, falling back to the system UI stack — no webfont request, so the first paint is never blocked. Monospace carries anything the machine produced: URLs, hashes, JSON, headers. If it came from an API, it is monospace.

Voice

✓ “Schema already known — reused cached interface, no Gemini call.”
✕ “Awesome! We've magically supercharged your API! 🚀”
✓ “The browser could not reach this endpoint. It may not send CORS headers.”
✕ “Oops! Something went wrong.”

Say what happened and what it means for the user. Name the real cause, including when the cause is us. No exclamation marks, no emoji, no congratulating the user for clicking a button.

Don’ts

✕ Recolour the mark, outline it, or place it on a busy photograph.
✕ Use amber for emphasis. Amber means a value changed.
✕ Add a second typeface, or set body copy in monospace.
✕ Animate for delight. Motion confirms an action or it does not ship.
✕ Put the tile behind the mark when it already sits on ink.
